# Stock Portfolio Tracker

A simple Stock Portfolio Tracker developed using Python for the CodeAlpha Python Programming Internship.

## Task
Calculate the total investment value of stocks based on manually defined stock prices and user-entered quantities.

## Features
- Hardcoded stock price dictionary
- User can enter stock symbols
- User can enter stock quantities
- Calculates individual stock investment values
- Calculates total portfolio investment
- Validates user input
- Saves portfolio details to a text file

- verification useful
